**MT 内存工具**是一款专为 iPhone 设计的内存分析与调试应用。它将数据搜索、稳定定位、深入分析、修改验证与结果保存集中在一个易于操作的界面中。

## 主要功能

### 🔎 内存搜索
- 精确搜索、范围搜索、模糊与变化搜索。
- 联合、临近、文字等多种搜索方式。
- 支持不同数据类型的查看、筛选与批量处理。

### 🎯 稳定定位
- 多级指针搜索，帮助寻找更稳定的数据位置。
- 特征定位与结果验证，减少重复搜索。
- 保存常用结果，方便后续继续分析。

### 🧭 分析与调试
- 内存查看器，查看目标地址附近内容。
- 数据与代码断点，辅助追踪变化。
- 寄存器、调用信息与汇编查看，帮助理解执行现场。

### ✏️ 修改与保存
- 数值修改、批量修改、冻结与解冻。
- 对支持的指令进行修改与恢复。
- 将常用操作整理为插件或自动化流程。

### 📱 手机操作体验
悬浮操作、横竖屏适配、浅色与深色主题、中文界面，并支持与其他调试工具配合使用。

## 使用场景

| 你的需求 | MT 可以帮你 |
| --- | --- |
| 寻找未知数据 | 逐步搜索和筛选候选结果 |
| 地址每次都会变化 | 尝试指针与特征定位 |
| 想了解数据为何改变 | 查看断点与执行现场 |
| 要反复验证修改 | 保存、恢复并复用操作 |
| 想整理调试成果 | 使用插件与流程保存结果 |
